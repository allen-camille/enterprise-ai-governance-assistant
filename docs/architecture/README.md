\## Design Principles



All artifacts in this directory adhere to the following principles:



\- Governance-first design

\- AI as analytical support, never decision-maker

\- Human-in-the-loop as a mandatory requirement

\- Deterministic and methodical behavior

\- Traceability and auditability

\- Risk-based analysis

\- Clear separation of responsibility between AI and organization
